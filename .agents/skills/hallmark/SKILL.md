# Hallmark — UI Craft & Anti-Slop Design System

Enforces high-density, accessible, and purposeful user interfaces while strictly preventing generic AI-generated aesthetics.

## Core Design Invariants for DevSparks DeployCheck

1. **Strict Light Theme Only:**  
   - App background: `#F7F9FC`
   - Card surfaces: `#FFFFFF`
   - Primary text: `#172033`
   - Secondary text: `#667085`
   - Borders: `#E4E7EC`
   - Primary Brand Blue: `#3563E9`
   - **Never introduce dark mode, dark panels, or dark theme toggles.**

2. **No AI Clichés (Anti-Slop):**  
   - No floating colorful blobs or unmotivated neon gradients.
   - No repetitive, empty decorative cards that convey no information.
   - No fake operational metrics or simulated CI check marks.
   - Use purposeful data hierarchy and readable tabular density.

3. **KPI & Chart Standards:**  
   - Every metric card must feature a clear label, value, comparison period, and explicit empty/loading/error states.
   - Charts must include titled axes, readable light gridlines, timestamps, and accessible textual summaries.
