# ECC Minimal Profile — Structured Engineering Harness

Selective high-discipline engineering workflows from ECC for Antigravity.

## Core Workflows

1. **Research-First Development:**  
   Before creating or modifying code, inspect existing patterns and read specifications thoroughly.
2. **Test-Driven Refinement (TDD):**  
   Define test cases (unit or fixture tests) demonstrating the expected behavior alongside implementation.
3. **Structured Review Gates:**  
   Review changes across security, accessibility, and architectural boundaries before declaring a milestone complete.
4. **Minimal Footprint:**  
   Do not introduce overlapping hooks or redundant rule engines.
