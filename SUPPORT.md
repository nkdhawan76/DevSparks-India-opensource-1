# Getting Support for DevSparks DeployCheck

We are glad you are using and contributing to **DevSparks DeployCheck**!

---

## Channels for Help

### 1. Documentation
Start by reviewing our architectural and design specifications in the [`docs/`](docs/) directory:
- [Product Requirements (PRD)](docs/PRD.md)
- [Architecture Requirements (ARD)](docs/ARD.md)
- [Code Review Guidelines](docs/development/CODE_REVIEW.md)
- [Versioning Guidelines](docs/releases/VERSIONING.md)

### 2. GitHub Discussions
For architectural questions, general inquiries, feature ideation, and community sharing:
- Visit **GitHub Discussions** in our repository.

### 3. Bug Reports & Issues
If you encounter a reproducible defect in implemented features:
- Search existing issues to avoid duplicates.
- Submit a structured report using our [Bug Report Template](.github/ISSUE_TEMPLATE/bug_report.yml).

### 4. Security Concerns
For security-related issues, please refer to [SECURITY.md](SECURITY.md). Do not post security flaws publicly.
